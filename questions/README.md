# Questions

> Preserve productive uncertainty outside the meeting agenda.

## What belongs here

Maintain `open-questions.md` and `resolved-questions.md`. Each question needs an origin, evidence, context, and what would count as progress or resolution. Link to issues only when action is warranted.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

An unresolved question is not necessarily a failure. Avoid premature closure.
