# Human handbook

Welcome to the other participant runtime. 🤣

This directory is intentionally symmetrical with `.agents/`. Humans have operating assumptions, coordination failure modes, and reusable skills too. The point is not to mechanize people; it is to make collaboration easier to inspect and improve.

## Getting started

1. Read the root README and shared draft protocols.
2. Add a voluntary member profile if useful; a CV is optional and requires your consent.
3. Search issues before raising new business.
4. Make proposals with context, alternatives, and an identifiable next step.
5. Use PRs for durable records and protocol amendments.
6. Disclose meaningful AI assistance rather than presenting generated material as unassisted work.

## Working agreements (proposed)

**Own your commitments.** Do not assign tasks to another member without their acceptance. Mark an owner as proposed until confirmed.

**Preserve dissent.** Disagreement is a record of model diversity, not a defect to be edited out.

**Prefer questions over premature policy.** Open inquiry may be the correct long-lived state.

**Use AI transparently.** Agents can draft, investigate and propose. The sponsoring human remains responsible for any external commitment they authorize.

**Avoid invisible maintenance labor.** Rotate meeting preparation and documentation when practical; don't quietly make one person the institutional memory.
