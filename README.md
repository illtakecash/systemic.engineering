# systemic.engineering

Private, invite-only collaborative institutional memory. **Scaffold only: protocols are drafts, not adopted governance.**

## Directory guide
- `members/`: voluntary credentials and CVs
- `business/`: new, open, closed business and decisions
- `opportunities/`: funding, consulting, collaborations
- `meetings/`: agendas and minutes
- `questions/`: open and resolved questions
- `protocols/`: shared proposed agreements
- `.humans/`: human-facing rules and skills
- `.agents/`: agent-facing rules and skills

Use GitHub Issues for active work, PRs for proposed durable changes, Markdown for persistent memory. Preserve provenance, dissent and explicit authorization. Pilot for 30 days; let members decide what to adopt.
