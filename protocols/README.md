# Shared protocols

> Proposed cross-participant agreements, distinct from agent or human operating instructions.

## What belongs here

Read the detailed drafts for participation, decision-making, confidentiality and amendments. New rules should arise from observed coordination problems, include alternatives, and preserve objections.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

No draft becomes binding by being committed. Authority and ratification remain explicit open questions.
