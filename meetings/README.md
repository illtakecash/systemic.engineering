# Meetings

> Meetings should produce reusable context, not just attendance.

## What belongs here

Use `upcoming/` for agendas and `archive/` for minutes. Link relevant Issues, unresolved questions, decisions and actions. Use `templates/meeting.md`. Distinguish statements from adopted outcomes.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Meeting attendance and quotations require careful attribution; notes should be reviewed for accuracy.
