# Meeting archive

> Keep a durable, navigable record of group deliberation.

## What belongs here

Include date, attendees when consented, discussion summary, linked sources, decisions with authority, dissent, accepted actions and follow-up questions. Correct disputed notes visibly.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Minutes are a record of discussion, not proof of universal agreement.
