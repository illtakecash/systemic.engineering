# Upcoming meetings

> Prepare agendas from actual open work rather than inventing business.

## What belongs here

Include date, location or link (if appropriate), facilitator, proposed agenda, linked issues, desired outcomes, pre-reads and access restrictions. Mark proposed items clearly.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Don't post private calendar links or attendee information without permission.
