# Member registry

> The registry makes expertise discoverable without turning credentials into a hierarchy.

## What belongs here

Each member may add a directory with a profile using `templates/member-profile.md`; CVs are optional and require the subject's explicit consent. Link professional work rather than copying confidential artifacts. Members own corrections to their profiles.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Questions: What expertise is available? Who is interested in collaboration? Which information is voluntarily public to the group?
