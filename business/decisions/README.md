# Decision records

> A decision is a traceable institutional claim, not just a merged file.

## What belongs here

Use `templates/decision.md`. Include proposal, authority, affected parties, alternatives, objections, method of approval, date, implementation owner and reconsideration triggers.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Until the group adopts a decision rule, mark collective decisions as provisional.
