# Business tracking

> GitHub Issues own active status; folders preserve durable outcomes and context.

## What belongs here

Use `new/` for proposed agenda material, `open/` for long-running matters, `closed/` for archived outcomes, and `decisions/` for durable decision records. Each record should link its issue, proposer, evidence, objections, next action and disposition.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Do not mark a proposal adopted merely because an issue closes or a PR merges.
