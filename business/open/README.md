# Open business

> Active topics requiring follow-through.

## What belongs here

Use the Issue as the status source. Durable files should summarize context, alternatives, blockers, accepted owners and next review. Link meetings and questions rather than copying content.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

No implied owner; tasks require acceptance.
