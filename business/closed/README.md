# Old / closed business

> Preserve outcomes so the same arguments do not recur without context.

## What belongs here

Archive the original question, evidence, disposition, reasons, unresolved objections, and conditions that justify reopening. Link the closing Issue and any decision record.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Closed means disposition recorded, not necessarily unanimous agreement.
