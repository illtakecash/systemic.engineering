# Collaborations

> Joint research, writing, speaking, prototypes and non-financial partnerships.

## What belongs here

Describe shared objective, potential participants, expected outputs, resources, publication plans, attribution and any intellectual-property concerns.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Record whether collaboration is exploratory or accepted; do not presume a joint entity exists.
