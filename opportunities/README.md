# Opportunities

> Track actionable ways members can collaborate, secure funding or earn revenue.

## What belongs here

Separate `funding/`, `consulting/`, and `collaborations/`. Open an Issue with source, eligibility, deadline, interested members, confidentiality constraints and next action. Use `templates/opportunity.md` for enduring records.

## Suggested workflow

1. Search for an existing issue, question, or record.
2. State the origin and purpose of the contribution.
3. Link evidence, affected participants and relevant existing work.
4. Record status and next action without implying consent.
5. Use a PR for durable revisions; preserve corrections and dissent.

## Boundary

Do not disclose clients, represent members as committed, or submit applications without authorization.
